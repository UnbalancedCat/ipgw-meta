# ADR-0020：有界静态 CAS 语法观察

维护者于 2026-10-30 确认 [静态语法工作包](../../operations/development-validation.md#p3-static-syntax-proposal)，批准离线可行性、规范、实现、验收和有判别价值时的独立交付；不授权新的真实窗口。ADR-0019 的旧回执与包保持原义。

新路径使用固定版本成熟静态 parser 的受审计派生代码，只增加预算、取消、来源位置和注释区间记录；不导入 JavaScript 运行时，不运行脚本。候选采用 Goja `v0.0.0-20261008201629-63c541af38f8` 的 parser/AST，MIT 许可保留；模块和逐文件派生哈希纳入快照，资源/语义验收失败时不交付真实入口。所有输入必须来自明确内存，source map 自动读取关闭，原始错误不输出。

语法事实分为词法上下文、标识符类别、直接字面量赋值及出现位置（顶层、函数内、控制结构内、其他）。赋值出现不表示执行、最终值、实际加密用键或正确键；use_relation 永远 unknown。只对可证明的 RSA 字面量生成本轮相等标签。未知节点/范围或不支持语法不得提升为完整成功；不改变产品文本取键和 SDK 认证逻辑。

保持已批准来源和输入预算。扫描、解析和 AST 遍历分别有累计工作/深度检查，长单 token 内可取消；进程硬终止和内存保护须在原生验收中实际成立。派生 parser 与未修改上游做合成差分，确认预算内正常解析结果未改变。不能仅凭外部 context 断言不可取消的库已受限。

独立 `auth-static-context-dev` / schema 2 与旧观察分离；采用原 SDK 采集器的同一消费路径，零额外来源、profile、密码、POST、activation、logout。新分析只有在凭据边界、完整来源及保护成立后运行；无法解释或超限时只报告闭集拒绝，不恢复请求。发布证据、Candidate、公共产品接口不变。
